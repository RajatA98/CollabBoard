## Color System

Each collaborator automatically gets a unique color:
- Generated by `hashColor(user.uid)` function
- Consistent across sessions for same user
- Applied to both cursor dot and label background
- Example colors: `#ff5733`, `#33d9ff`, `#a233ff`

## Architecture

```
Mouse Move Event
      ↓
Board.handleMouseMove()
      ↓
useCursors.updateCursor(x, y)
      ↓
Firebase RTDB: setCursor(boardId, userId, cursorData)
      ↓
[Real-time sync via onCursorsChange listener]
      ↓
useCursors receives update → filters out self
      ↓
Canvas receives remoteCursors prop
      ↓
RemoteCursor components render (one per collaborator)
      ↓
User sees colored dot + name label!
```

## Troubleshooting

If cursors still don't appear after testing, check:

1. **Firebase RTDB Rules**: Ensure read/write permissions are set
   ```json
   {
     "rules": {
       "boards": {
         "$boardId": {
           "cursors": {
             ".read": "auth != null",
             ".write": "auth != null"
           }
         }
       }
     }
   }
   ```

2. **Environment Variables**: Verify `.env` has `VITE_FIREBASE_DATABASE_URL`

3. **Browser Console**: Look for Firebase connection errors

4. **Network Tab**: Check if Firebase RTDB requests are succeeding
